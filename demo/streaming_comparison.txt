============================================================
OBSERVATION
============================================================

The non-streaming endpoint returns the completed response as a
single HTTP response after the model finishes.

The streaming endpoint returns Server-Sent Events progressively,
allowing the client to receive and display response content while
generation is still in progress.

Total completion time is not necessarily lower with streaming.
The primary user-experience benefit is progressive delivery and
reduced perceived waiting time.

The backend also validates the final streaming model status before
accepting the streamed response.
